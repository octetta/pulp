# Emulating Vintage Digital Synthesizers in Skred

Skred's DSP engine is deeply influenced by the architectures of the most iconic digital synthesizers of the 1980s: the Casio CZ series, the Korg DW-8000, and the Yamaha DX-7. 

By combining arbitrary multi-stage envelopes, precise phase distortion, phase modulation, and digital delay lines, Skred is capable of faithfully emulating these classic hardware units while extending their capabilities into modern territory (like applying 80s phase distortion to modern wavetables for tearing Dubstep basses).

This document breaks down how to emulate the architectures of these three legendary synths using Skred's flat-array syntax.

---

## 1. Casio CZ: Phase Distortion & The Cosine Secret

Phase Distortion works by applying a "kinked" or bent phase trajectory to a base waveform. For example, a CZ "sawtooth" is generated by reading a wave very quickly for the first half of the cycle, and very slowly for the second half. 

The mathematical "kink" (the sudden change in playback speed) in these algorithms always happens precisely at the midpoint of the phase (`0.5`). 

**Why does the base waveform matter?**
* **The Casio CZ** used a **Cosine wave** (technically a negative cosine). At phase `0.5`, a cosine wave is at its absolute peak (`1.0` or `-1.0`). Bending the phase here creates a continuous wave with a sharp, pointed top. This generates warm, bright, brassy harmonics.
* **A standard Sine wave** (`w 0`), however, is at exactly `0.0` (a zero-crossing) at phase `0.5`. Bending the phase here creates a jagged, asymmetrical slice right through the audio axis, resulting in brittle and buzzy artifacts.

**The Fix in Skred:**
To get mathematically authentic Casio CZ sweeps, always use **`w 47` (Cosine)** as your base waveform. It sounds identical to a Sine wave on its own, but behaves completely differently under phase distortion.

### Classic Casio-Style Brass
Here is a classic resonant brass patch using the Cosine wave (`w 47`) and PD mode `6` (Resonant Saw):
```skred
v0 w47 a8 c6,-0.15 ct0.01,0.3,0.35,0.45 cd0.9 t0.015,0.35,0.55,0.45 f110 l1
```


### Funky Pulse Bass
The CZ is legendary for its punchy, synthetic basses. This patch uses Mode 1 (Sawtooth to Pulse) with a negative distortion depth to drive a strong transient pulse that decays into a dark, funky body.
```skred
v0 w47 a8 c1,-0.65 ct0.001,0.16,0.08,0.22 cd1.0 t0.002,0.24,0.62,0.28 f55 l1
```

### Glassy Bell
Bells and chimes are a staple of Phase Distortion. This uses Mode 4 (Double Sine). A very short PD envelope creates a sharp metallic transient, while the amplitude envelope rings out smoothly over almost two seconds.
```skred
v0 w47 a8 c4,0.08 ct0.001,0.55,0,0.7 cd0.8 t0.001,1.8,0,1 f440 l1
```

### Syn-Tom (Authentic CZ Percussion)
The original Casio CZ completely lacked a pitch envelope! To create percussion like Toms or Kicks, programmers had to fake a pitch envelope by applying a massive, lightning-fast Phase Distortion decay over a very low fundamental frequency. As the wave rapidly collapses from a bright Saw down to a pure Sine, the human ear perceives the loss of high-harmonics as a pitch-drop "thwack"!
```skred
v0 w47 a8 c1,0.9 ct0.001,0.05,0,0 cd1.0 t0.001,0.4,0,0 f65 l1
```

## Beyond Casio: Modern Neuro & Dubstep Bass

The Casio CZ was strictly limited to distorting cosine waves. Modern wavetable synthesizers (like Xfer Serum or Skred) allow you to apply Phase Distortion to *any* waveform.

When you apply PD to a complex wavetable (like the built-in Korg DWGS waves from `w 15` to `w 30`), you are dynamically stretching and squishing its internal harmonics. Because the wave is full of high-frequency bumps, bending the phase creates wild, metallic, vocal, and "tearing" sounds that a standard filter sweep could never achieve.

This is the secret behind the modern "Skrillex Growl" or Neurohop bass: **Applying heavy phase distortion to a complex waveform, and modulating the distortion depth with a tempo-synced LFO or Envelope.**

### Skred Neuro/Dubstep Patches

Skred provides the `C osc, depth` command, which allows you to modulate the Phase Distortion depth of a voice using another voice (an LFO).

**1. The Classic "Yoy" Growl**
This patch uses a slow LFO (`v1`) to violently sweep the Phase Distortion depth of a Korg DWGS String wave (`w15`). The result is a tearing, vocal-like formant sweep (the classic "Yoy" bass).
```skred
# Voice 1: Fast LFO (wobbling at 6Hz)
v1 w0 m1 f6 a1 t0,10,1,1 l1

# Voice 0: Complex wave (w15), pitched to 55Hz (A1). 
# The LFO on v1 modulates the PD depth (C 1, 0.8)
v0 w15 c1,0.2 C1,0.8 a8 f55 g0.1 t0.1,2,0.5,1 l1
```

**2. The Metallic Neuro Reese**
This patch uses PD mode 2 (Square folding) on a Korg Organ wave (`w21`). The modulation creates a metallic, squelchy tearing sound perfect for Neurofunk drops.
```skred
# Voice 3: LFO sweeping at 4Hz
v3 w0 m1 f4 a1 t0,10,1,1 l1

# Voice 2: Organ wave (w21), folded with PD mode 2
v2 w21 c2,0.5 C3,0.5 a8 f55 g0.15 t0.05,1,0.5,1 l1
```

**3. The Snappy "Modern Talking" Pluck**
A staple of 2010s Dubstep, this uses Skred's built-in PD Envelope (`ct` and `cd`) instead of an LFO to create a fast, punchy squelch at the start of the note.
```skred
v0 w24 c5,-0.5 ct0.01,0.2,0.1,0.3 cd0.8 a8 f55 t0.01,0.4,0,0 l1
```

### PD Modes Reference in Skred
When using `c mode, depth`, the mode defines the distortion shape:
* **Mode 1:** Sawtooth -> Pulse
* **Mode 2:** Square (Folded Sine)
* **Mode 3:** Triangle
* **Mode 4:** Double Sine
* **Mode 5:** Sawtooth / Pulse Window
* **Mode 6:** Resonant Sawtooth (Windowed)

### Architectural Secrets: Mutes and Glides

**Why do we use `m1` (Mute) on modulators?**
In Skred's architecture, if you want an LFO to be completely silent but still modulate another voice, you might be tempted to just set its amplitude to zero (`a0`). However, because modulation is computed *after* the envelope stage, `a0` will literally squash the LFO signal to zero, stopping it from doing any modulation! 
By using `m1` (Mute), the voice still generates a full-strength enveloped signal (`a1`) that other voices can read, but it simply disconnects its output from the master mix bus. Always use `a1 m1` for silent LFOs!

**Glissando / Portamento (`g`)**
Neuro and Dubstep basses frequently glide between pitches. You can achieve this seamlessly in Skred using the `g time` command.
For example, adding `g 0.1` to your bass voice will make it glide smoothly between frequencies over 100 milliseconds whenever a new pitch is triggered, making those Phase Distortion sweeps sound incredibly fluid and rubbery.

### Putting It Together: Live Neuro Sequencer
If you want to wow people with a live performance, you can hook your Dubstep growl into Skred's built-in step sequencer!
By combining a note stream with a repeating sequence pattern, you can have the bassline play itself while you dynamically tweak the Phase Distortion depth or wobble speed live.

```skred
# 1. Setup the Dubstep Growl (V1 is LFO, V0 is Carrier)
v1 w0 m1 f6 a1 t0,10,1,1 l1
v0 w15 c1,0.2 C1,0.8 a8 g0.1 t0.1,2,0.5,1 

# 2. Feed a bassline into Stream 1 (/SS 1)
(35 38 40 37) /SS 1

# 3. Bind a pattern to the sequencer (x0).
# On trigger, it grabs the next note from Stream 1 (n&1) and plays it (l1)!
[v0 n&1 l1] x0
```
With the sequence running, you will hear a tearing, gliding Neurohop bassline automatically looping and modulating itself!

#### Live Tweaking Examples
While the sequencer is driving the bassline, you can type commands to mutate the sound in real-time. Try pasting these commands one by one while it plays:

* **Change the wobble speed:** Make the LFO rapidly flutter or slowly sweep.
  `v1 f12` (Fast)
  `v1 f2` (Slow)
* **Push the distortion over the edge:** Increase the depth to make the synth scream.
  `v0 C1, 1.5`
* **Change the filter texture:** Switch the PD Mode from 1 (Pulse) to 2 (Folded Square) to instantly make the bass sound metallic and hollow.
  `v0 c2, 0.2`
* **Massive Glide:** Increase the glissando time so the notes slide sluggishly into each other.
  `v0 g0.5`

## Advanced: Multi-Stage Envelopes (`te`)
While the classic `t` command provides standard ADSR (`Attack, Decay, Sustain, Release`), Skred now natively supports DX-7 / CZ-1 style multi-stage Rate/Level envelopes!

You can construct complex envelopes using the `te` (Time Extended) command. It accepts an array of `[Time, Level]` pairs.
To define the **Sustain Point** (the stage where the envelope pauses and holds until the key is released), simply make its time negative (`-1`).

### 6-Stage Pluck Example
This patch uses a 6-stage amplitude envelope to create a double-strike transient, hold a quiet sustain, and fade out very slowly.
```skred
v0 w47 c1, 0.4 a8 f110 
# Stage 1: 10ms to reach 1.0 amplitude
# Stage 2: 50ms to drop to 0.4
# Stage 3: 20ms to spike back to 0.8
# Stage 4: 100ms to decay to 0.3
# Stage 5 (Sustain): -1 time tells the engine to hold at 0.3 until key release!
# Stage 6 (Release): 800ms to fade to 0.0
(0.01 1.0  0.05 0.4  0.02 0.8  0.1 0.3  -1 0.3  0.8 0.0) te 
l1
```
Because `te` accepts standard Skode arrays, you can easily use `k-synth` to procedurally generate massive, complex envelopes with dozens of stages and drop them right onto the stack!

### Authentic CZ-1 Brass (8-Stage Envelope)
To fully emulate a flagship Casio CZ-1, we need an 8-stage envelope for BOTH the Amplitude (DCA) and the Phase Distortion (DCW)! 

Skred provides `cte` (Phase Distortion Time Extended) specifically for this.
In this patch, the PD envelope (`cte`) decays faster and lower than the amplitude envelope (`te`), which gives the brass that classic "mwah" harmonic filter sweep before it settles into a warm sustain.

```skred
v0 w47 c1,0 cd1.0 a8 f220

# Phase Distortion 8-Stage Envelope
# Drops sharply, holds at 0.6, fades out moderately.
(0.05 1.0  0.15 0.6  -1 0.6  0.3 0.0) cte

# Amplitude 8-Stage Envelope
# Sustains louder (0.8) and holds until key release, fading out slower.
(0.02 1.0  0.1  0.8  -1 0.8  0.4 0.0) te

l1
```

## The CZ-101 Greatest Hits (and the Python Transpiler)

Because the original Casio CZ hardware used a proprietary `0-99` scale for its envelope rates and levels (rather than true seconds and floats), translating patches by hand is tedious. 

To solve this, we have provided a utility script in the root directory called **`cz_to_skred.py`**. 
This script contains an exponential mathematical curve that maps Casio rates to true seconds, and automatically transpiles CZ parameters into Skred `te` and `cte` arrays (handling the `-1` sustain flag calculations). If you ever download a CZ SysEx (`.syx`) bank online, you can easily extend this script to parse the binary file and generate an entire library of Skred `.sk` patches in milliseconds!

Below is the output generated by the script for four legendary CZ-101 factory presets: 

Notice how `w47` (Cosine) is used as the foundational wave, and the `-1` flag is injected to mark the exact sustain stage defined by the original Casio programmers.

```skred
# === Elec Piano 1 ===
# Mode 1 (Saw). Fast pluck, drops to woody sustain.
v0 w47 c1,0 cd1.0 a8
( 0.001 1.00 0.808 0.61 1.025 0.40 -1.489 0.00 1.489 0.00 ) cte
( 0.001 1.00 0.915 0.71 -1.252 0.00 1.489 0.00 ) te

# === Fretless Bass ===
# Mode 1 (Saw). Plucky, immediate decay to 0, no sustain.
v0 w47 c1,0 cd1.0 a8
( 0.001 1.00 0.808 0.51 -1.025 0.00 20.000 0.00 ) cte
( 0.001 1.00 0.915 0.61 -1.025 0.00 20.000 0.00 ) te

# === Fairlight Vox (Choir) ===
# Mode 4 (Double Sine). Creates vocal formants. Slow attack/release.
v0 w47 c4,0 cd1.0 a8
( 0.605 1.00 -0.808 0.81 20.000 0.00 ) cte
( 0.808 1.00 -0.808 0.81 20.000 0.00 ) te

# === Glass Bells ===
# Mode 4 (Double Sine). Instant transient, rings out to pure sine wave.
v0 w47 c4,0 cd1.0 a8
( 0.001 1.00 -0.416 0.00 20.000 0.00 ) cte
( 0.001 1.00 -1.489 0.00 20.000 0.00 ) te
```

## Emulating the Korg DW-8000 (ADBSSR Envelopes)
The Korg DW-8000 is a legendary hybrid synthesizer that paired digital waveforms with warm analog filters. Instead of a standard ADSR envelope, it used a highly expressive 6-parameter **ADBSSR** envelope (Attack, Decay, Break-Point Level, Slope, Sustain Level, Release).

Because Skred's multi-stage envelope arrays are completely arbitrary in length, an ADBSSR envelope maps perfectly into a **5-stage Skred array**!

To make this possible, we provide the **`fte` (Filter Time Extended)** command alongside `te` (Amplitude Time Extended).

```skred
# === Classic DW-8000 Brass (with Digital Chorus!) ===
# Medium attack, drops to a high break point, slow slope to sustain.
# Plus the legendary DW-8000 digital delay line acting as a Chorus!

# Setup the DW-style Delay on Track 1 (short delay, medium LFO mod, no feedback)
DL 1, 0, 15, 0, 6, 18, 10

# --- OSC 2 (Detuned) ---
v1 w2 a 8
N 0, 7            # Detune OSC 2 by +7 cents for analog thickness
r1 ds1.0          # Route voice to Track 1 and send full signal to Delay
J24 0 K3000 Q0.3  # Analog Lowpass Filter
( 0.438 1.00  0.655 0.65  0.909 0.32  -1 0.32  0.735 0.00 ) fte
fd 0.8
( 0.211 1.00  0.438 0.81  0.315 0.65  -1 0.65  0.578 0.00 ) te

# --- OSC 1 (Master) ---
v0 w2 a 8
G 1 H 1           # Link Note and Trigger to OSC 2 (v1)
r1 ds1.0          # Route voice to Track 1 and send full signal to Delay
J24 0 K3000 Q0.3  # Analog Lowpass Filter
( 0.438 1.00  0.655 0.65  0.909 0.32  -1 0.32  0.735 0.00 ) fte
fd 0.8
( 0.211 1.00  0.438 0.81  0.315 0.65  -1 0.65  0.578 0.00 ) te
```

Just like `cz_to_skred.py`, we have included a **`dw8000_to_skred.py`** utility script in the root directory that mathematically converts Korg's proprietary `0-31` ADBSSR parameters directly into perfect Skred arrays!

## 3. Yamaha DX-7: 6-Operator Phase Modulation

Skred's architecture now fully supports emulating Yamaha DX-7 patches through phase distortion and its 6-operator matrix structure!

### 6-Operator Linkages (`G` and `H`)
In the DX-7, "Operators" are arranged into 32 different "Algorithms" (routing configurations). In Skred, you can build any DX-7 algorithm by linking up to 6 voices together using the `G` (MIDI note link) and `H` (Velocity link) commands. 

The `G` command lets a master voice broadcast its MIDI note data to up to 6 target voices, which function as the operators:
```skode
# Link voice 0 to voices 1, 2, 3, 4, 5, and 6
v0 G 1 2 3 4 5 6
```
Because the `G` array now supports 6 slots, you have enough linkages to drive a full 6-operator FM patch from a single trigger voice.

### The Global Pitch Envelope (`pte`)
DX-7 patches rely heavily on a Global Pitch Envelope to create characteristic brass swells, plucks, and drum transients. Skred implements this via the `pte` (Pitch Time Extended) command, which works identically to the amplitude (`te`) and phase distortion (`cte`) multi-stage envelopes.

To use the pitch envelope:
1. Define the multistage array and apply it using `pte`.
2. Enable it with `1 pt`.
3. Set the modulation depth (in semitones) using `pd` (Pitch Depth).

```skode
# A classic DX-7 pitch dive bomb
# Starts at +12 semitones, drops to normal pitch, sustains, then drops -12 semitones on release
( 0.01 1.0  0.5 0.0  -1 0.0  1.0 -1.0 ) pte
1 pt    # Enable pitch envelope
12 pd   # Depth is 12 semitones
```

### Combining Them (Example Algorithm)
To create a complex DX-7 Algorithm, you'll typically set up one master voice (the "carrier") that links to several other voices (the "modulators"). You can then route the modulators to apply Phase Distortion (`c`, `cd`) or Ring Modulation (`XM`) to the carrier, shaping the sound dynamically over time using each operator's individual `te` and `cte` envelopes!

### DX-7 Solid Bass Example (Algorithm 16)
In DX-7 Algorithm 16, Operator 1 (carrier) is modulated by Operator 2. 
We can build this easily in Skred using two voices, linking their notes with `G`, and setting up Phase Modulation using `FF 2` (Lookup-Phase Modulation) and the `F` cross-voice modulation command.

```skode
# Operator 2 (Modulator)
v1 w0 a 0 N 12 # Sine wave (+1 Octave for a 2:1 FM ratio)
m 1            # Mute the audio output (modulators shouldn't be heard directly)
( 0.01 1.0  0.2 0.7  -1 0.7  0.4 0.0 ) te # Modulator Envelope (Sustained)

# Operator 1 (Carrier)
v0 w0 a 10     # Sine wave (boosted 10dB for bass presence)
G 1 H 1        # Link note (G) and velocity trigger (H) to Modulator (v1)
F 1 2.5        # Phase Modulate (F) using voice 1 with a depth of 2.5
FF 2           # Set FM mode to 2 (Phase Modulation - true DX-7 style!)
( 0.01 1.0  0.5 0.7  -1 0.7  1.0 0.0 ) te # Carrier Envelope (Sustained)
```

This effectively builds a 2-Operator Phase Modulation synth where `v0` controls the pitch and triggers the envelopes of both itself and its modulator `v1`!

## Python Translation Utility Scripts

To assist in converting parameters from these classic 1980s synthesizers into Skred patches, the repository includes three python scripts:
- `cz_to_skred.py` (Casio CZ Series)
- `dw8000_to_skred.py` (Korg DW-8000)
- `dx7_to_skred.py` (Yamaha DX-7)

These scripts serve primarily as **translation engines**. They contain the complex exponential math required to convert the proprietary, non-linear hardware curves (such as Casio's 0-99 rates or Korg's 0-31 rates) into standard Skred absolute time seconds and linear amplitudes. Each script contains a dictionary of classic "Greatest Hits" factory presets that it compiles down into Skode array syntax when run.

> [!WARNING]
> **Translation Limitations:** 
> These scripts are *simplified abstractions* designed for demonstration and architectural scaffolding. They do **not** support 100% of the parameters required to losslessly convert random SysEx patches. 
> 
> For example:
> * The `dw8000_to_skred.py` script currently lacks support for the Noise Generator, LFO (MG) routing, Auto-Bend pitch envelopes, and independent oscillator waveforms.
> * The `dx7_to_skred.py` script generates a simplified 2-operator (Algorithm 16) structure rather than parsing all 32 algorithms and 155 global parameters.
> 
> To perfectly emulate a patch from a magazine or SysEx dump, you must use these scripts to translate the envelope timings, but manually wire the missing modulation architectures in Skred yourself.

## 4. Advanced: Pulse Width Modulation & The Ghost Flanger

Casio's Phase Distortion (Mode 1: Saw -> Pulse) can be used to mathematically sweep the phase of Skred's wavetables. Depending on which square wave you use, you get two completely different, incredibly powerful effects.

### True Analog PWM (Using `w 16`)
If you apply `c 1` to an edge-aligned square wave (like `w 16`), the phase distortion physically moves the edge of the square wave, creating mathematically perfect Pulse Width Modulation (PWM).

Here is an example using the `C <voice> <depth>` command to drive the PWM with a sine-wave LFO:
```skred
# Voice 2: The LFO
v2 w0 f 1 a 0 m 1  # 1Hz Sine wave. m1 mutes it from the master mix so it doesn't blow out your speakers!

# Voice 0: The PWM Carrier
v0 w16 a 5         # Analog edge-aligned square
c 1, 0.5           # Set base pulse width to 50%
C 2, 0.45          # Use LFO (v2) to continuously sweep the width +/- 45%
H 2                # Link triggers to LFO (v2) so its envelope opens, but DO NOT link pitch (G)
n 40               # Trigger the note
```

### The "Ghost Flanger" (Using `w 49`)
If you apply `c 1` to a *centered* pulse wave (like the analog `w 49` or digital `w 48`), the phase distortion stretches and squishes the edges of the pulse symmetrically. The pulse width stays exactly at 50%, but the entire pulse physically slides back and forth across the phase window!

Mixing a sliding pulse against a static pulse creates a massive comb-filtering flanger effect, entirely within the oscillator (no delay lines required):
```skred
# Voice 2: The LFO
v2 w0 f 0.5 a 0 m 1 # 0.5Hz Sine wave, muted from master mix

# Voice 1: The Static Pulse
v1 w49 a 3         

# Voice 0: The Modulated Pulse (Slides back and forth)
v0 w49 a 3
c 1, 0             # Mode 1, base phase 0
C 2, 0.9           # Use LFO (v2) to slide the pulse phase +/- 90%
G 1 H 1, 2         # Link Pitch (G) ONLY to v1. Link Triggers (H) to both v1 and v2!
n 40               # Trigger the notes
```
