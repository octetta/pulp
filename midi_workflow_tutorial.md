# Workflow Tutorial: From MIDI to Live Skode Performance

The `midi2skode` utility converts raw MIDI sequences into a blueprint of `.sk` patterns. However, it intentionally doesn't orchestrate the final song for you. Instead, it extracts the DNA of the MIDI file and organizes it so a human live-coder can take over.

Here is a step-by-step documentation of how a human edits the output to build a live Skode performance.

## Step 1: Generate the Raw DNA
First, run the tool with parameters that fit the song's natural rhythm. For the 124 BPM Sweet Dreams riff (which consists entirely of 8th-note syncopations), we use `--div 2` to chunk it perfectly into 2-bar blocks.

```bash
./midi2skode examples/Sweet_Dreams.mid --velocity --div 2 --steps 16 > raw_dump.sk
```

## Step 2: Understand the Architecture
Open `raw_dump.sk`. You will notice the tool has done something incredibly smart: it has separated every single MIDI Channel into its own independent stream of `y` patterns. 

For example, the first 2 bars of the song are split precisely into parallel patterns:
*   `y 10 yt [T0C0P0]`: Track 0, Channel 0 (The Bass Synth)
*   `y 164 yt [T0C1P0]`: Track 0, Channel 1 (The Lead Synth)
*   `y 268 yt [T0C2P0]`: Track 0, Channel 2 (The Arp)
*   `y 321 yt [T0C9P0]`: Track 0, Channel 9 (The Drums)

By isolating the instruments, the tool sets up a perfect **Master/Slave** architecture. You don't have to manually untangle chords or overlapping instruments!

## Step 3: Copy, Paste, and Setup
Create a new file, `sweet_dreams_live.sk`. 
Copy the `M124` tempo and the Macro Definitions block from the top of `raw_dump.sk`. 

Next, look at the `# Drum Note` comments generated by the tool. For `[T0C9P0]`, it says:
`# Drum Note 35: Acoustic Bass Drum`
This tells you exactly how to route your voices in Skred:
```skred
[sk/drums-kick.ks] /ks 1 k>d d>r /r100

v 9 vt [KickVoice] w 100 f 440 a 20  # Assign to v 9 so [Drm] uses it
v 0 vt [BassSynth] w 2   f 440 a 6   # Assign to v 0 so [ChA] uses it
```

## Step 4: The Live Orchestration (The Human Element)
Copy the exact patterns you want to jam with into your `sweet_dreams_live.sk` file.

Now, instead of hardcoding 100 bars of patterns linearly, you write a single **Arranger** pattern (`y 1`) that acts as the Master Controller. Because the patterns are already perfectly 16-steps long, you can trigger them in parallel!

```skred
y 1 yt [Arranger]
% 16  # 1 step = 1 full 2-bar pattern length

# Start the Groove! 
# We trigger the Bass (y 10), Lead (y 164), Arp (y 268), and Drums (y 321) simultaneously.
[ /z 10 1 /z 164 1 /z 268 1 /z 321 1 ] x 0

# The patterns will now loop infinitely in phase!
```

If you want to perform the chorus (which might be pattern `P4` in the dump), you simply drop another command into your Arranger to stop the `P0` patterns and start the `P4` patterns.

## Summary
The human flow is:
1. Dump the MIDI to a raw `.sk` text file.
2. Read the auto-generated comments to map your `.ks` synth patches and drum samples.
3. Extract the separated channel patterns you want to loop.
4. Write a master `y 1` Arranger to trigger them in parallel and jam live.
